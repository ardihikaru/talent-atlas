Arsitektur Peta Pendidikan Anak

Rancangan sistem untuk menjalankan peta graf pendidikan: backend Go dalam satu binary, ArcadeDB sebagai penyimpan graf, AI platform untuk ekstraksi dan saran, dan aplikasi web yang menampilkan graf beserta animasinya.

ArcadeDB

Semua nama memakai bahasa Inggris: database education, label dalam PascalCase, relasi dalam UPPER_SNAKE_CASE, properti dalam camelCase, dan paket Go dalam huruf kecil. Teks di layar tetap bahasa Indonesia. Skema dibuat lewat SQL, sedangkan baca dan tulis sehari-hari memakai Cypher. Keduanya berjalan di database yang sama.

Migrasi skema (SQL lewat HTTP, port 2480)

Ulangi pola ini untuk setiap label dan relasi pada model graf. Periksa sintaks terhadap versi ArcadeDB yang Anda pasang.

CREATE VERTEX TYPE Child IF NOT EXISTS;
CREATE PROPERTY Child.id IF NOT EXISTS STRING;
CREATE INDEX IF NOT EXISTS ON Child (id) UNIQUE;

CREATE VERTEX TYPE Competition IF NOT EXISTS;
CREATE VERTEX TYPE CompetitionEdition IF NOT EXISTS;
CREATE VERTEX TYPE Round IF NOT EXISTS;
CREATE VERTEX TYPE Document IF NOT EXISTS;
CREATE PROPERTY Document.id IF NOT EXISTS STRING;
CREATE INDEX IF NOT EXISTS ON Document (id) UNIQUE;

CREATE EDGE TYPE HAS_EDITION IF NOT EXISTS;
CREATE EDGE TYPE HAS_ROUND IF NOT EXISTS;
CREATE EDGE TYPE BELONGS_TO IF NOT EXISTS;
CREATE EDGE TYPE PARTICIPATES_IN IF NOT EXISTS;

Mencatat hasil satu babak lomba

Babak dirangkai dari lokal sampai internasional. Hasil anak menempel pada babak, bukan pada lomba.

MATCH (c:Child {id: $childId})
MATCH (comp:Competition {id: $competitionId})
MERGE (comp)-[:HAS_EDITION]->(e:CompetitionEdition {id: $editionId})
  ON CREATE SET e.year = $year
MERGE (e)-[:HAS_ROUND]->(r:Round {id: $roundId})
  ON CREATE SET r.tier = $tier, r.sequence = $sequence
MERGE (c)-[p:PARTICIPATES_IN]->(r)
SET p.result = $result, p.advanced = $advanced

Arsip dokumen lomba

Setiap unggahan melewati jalur yang sama, sehingga soal tahun lalu bisa dicari dan dipakai AI sebagai rujukan.

  1. Unggah

    Berkas masuk ke object storage dengan kunci competitions/{id}/{year}/{uuid}.pdf. Node Dokumen dibuat dengan jenis, judul, dan fileKey.

  2. Ekstraksi

    Teks PDF diambil dan dipotong per halaman atau per soal. PDF hasil pindai memerlukan OCR.

  3. Indeks

    Tiap potongan diberi embedding dan disimpan di indeks vektor ArcadeDB, terhubung ke dokumennya.

  4. Tautkan

    AI mengusulkan kompetensi yang dibahas tiap dokumen. Setelah Anda setujui, relasi COVERS dibuat.

  5. Perbarui

    Mengganti berkas membuat versi baru. Versi lama tetap tersimpan dan catatan Anda tidak hilang.

React dengan React Flow dan Motion

Prototipe menggambar node sebagai elemen HTML di atas garis SVG, dengan posisi yang ditentukan kolom tahap dan baris jenis node. React Flow memakai pendekatan yang sama, jadi tampilan dan animasinya bisa dipindahkan hampir satu banding satu. Pedoman animasi yang Anda tunjuk juga ditulis untuk React dan Motion.

Kapan memilih yang lain

  • Svelte dengan Svelte Flow lebih ringan, tetapi contoh dan komponen pendukung animasinya lebih sedikit.
  • Cytoscape.js atau Sigma.js menggambar di canvas dan kuat untuk ribuan node. Sebagai gantinya, animasi per node lewat CSS tidak bisa dipakai. Graf satu anak berisi puluhan sampai ratusan node, jadi belum perlu.

Data anak

  • Ke AI platform hanya dikirim id samaran dan sub-graf yang relevan, tanpa nama lengkap atau nama sekolah.
  • Setiap saran menyimpan node bukti yang dipakainya, sehingga bisa ditelusuri dan dikoreksi.
  • Berkas diakses lewat URL bertanda tangan yang berlaku singkat. Bucket tidak dibuka untuk publik.
  • ArcadeDB dan object storage dicadangkan terjadwal, dan pemulihannya diuji sebelum data nyata masuk.

Urutan pembangunan

  1. Graf dan input

    Migrasi skema, data master, endpoint observasi, endpoint graf. Aplikasi web menampilkan graf dari data nyata.

  2. Lomba dan arsip

    Edisi, babak, unggah PDF, daftar dokumen per tahun, kalender dan pengingat.

  3. Saran real time

    Worker, query celah, AI client, SSE, dan tombol terima atau tolak.

  4. Bakat dan keputusan

    Kesenangan, riwayat, dan bobot bukti untuk sinyal bakat. Beban mingguan, pembanding sekolah, embedding dokumen, dan pencarian referensi lintas tahun.
