Satu graf yang memuat perjalanan anak dari SD kelas 1 sampai kuliah: sekolah dan kurikulumnya, apa yang sudah dikuasai, minat, lomba, dan olahraganya, lalu di mana bakatnya terlihat dan bagian jalur mana yang masih berlubang.

Klik node untuk melihat properti, relasi, dan query-nya. Graf ini adalah ego-graph Raka: relasi dari node Anak tidak digambar sebagai garis, melainkan sebagai atribut pada node tujuannya (bar level = MASTERS.level). Kolom menunjukkan tahap tempat sebuah kompetensi diajarkan (TAUGHT_IN).

      Bahan referensi dari tahun-tahun sebelumnya
      

      MATCH (c:Competition {id: $competitionId})-[:HAS_EDITION]->(e:CompetitionEdition)
MATCH (d:Document)-[:BELONGS_TO]->(e)
OPTIONAL MATCH (d)-[:COVERS]->(k:Competency)
RETURN e.year AS year, d.type AS type, d.title AS title,
       d.fileKey AS fileKey, collect(k.name) AS competencies
ORDER BY year DESC, type
      
    
      
  
      

  
      
    
      Dari input ke saran
      
    
      Langkah 3 memicu langkah 4 sampai 6 secara otomatis, sehingga saran muncul beberapa detik setelah Anda menyimpan input.
      
    
        
      
      1. Anda memberi input
        Form, foto rapor, atau pesan bebas. Tiap input membawa tanggal dan sumber.
        2. 
      
      2. AI mengekstrak
        Teks bebas diubah menjadi JSON sesuai skema: kompetensi mana, level berapa. Yang ambigu ditanyakan balik.
        3. 
      
      3. Tulis ke graf
        Observasi dibuat baru, relasi MASTERS diperbarui dengan MERGE. Riwayat tetap utuh.
        4. 
      
      4. Ambil sub-graf
        Query mengambil celah, jalur prasyarat, dan observasi enam bulan terakhir.
        5. 
      
      5. AI menyusun saran
        Sub-graf dikirim sebagai konteks. Model wajib menyebut node bukti untuk tiap saran.
        6. 
      
      6. Simpan dan tampilkan
        Saran menjadi node yang menunjuk ke buktinya, lalu dikirim ke layar lewat SSE atau WebSocket.
        7. 
    
      
  
      

  
      
    
      Query inti
      
    
      Ditulis dalam Cypher, yang dijalankan ArcadeDB secara native. Semua nama label, relasi, dan properti memakai bahasa Inggris. Nilai seperti id dan tanggal batas dihitung di backend Go dan dikirim sebagai parameter. Query ini belum diuji di ArcadeDB.
      
    
      
      
      
        
      Celah menuju satu jurusan
      
        
      Menelusuri rantai prasyarat ke belakang dan mengembalikan kompetensi yang levelnya di bawah syarat.
      

      MATCH (c:Child {id: $childId})
MATCH (k:Competency)-[r:REQUIRED_FOR]->(m:Major {id: $majorId})
MATCH (base:Competency)-[:PREREQUISITE_OF*0..]->(k)
OPTIONAL MATCH (c)-[ms:MASTERS]->(base)
WITH k, r, base, coalesce(ms.level, 0) AS level
WHERE level < r.min
RETURN k.name AS requirement, base.name AS needsWork,
       level, r.min AS target
ORDER BY level, requirement
      
      
      
      
      
        
      Konteks untuk AI
      
        
      Satu baris berisi penguasaan, minat, dan observasi terbaru. Hasilnya dikirim sebagai JSON ke AI platform.
      

      MATCH (c:Child {id: $childId})
OPTIONAL MATCH (c)-[ms:MASTERS]->(k:Competency)
OPTIONAL MATCH (c)-[i:INTERESTED_IN]->(n:Interest)
OPTIONAL MATCH (o:Observation)-[:ABOUT]->(c)
  WHERE o.date >= date($since)
RETURN c.id AS child,
  collect(DISTINCT {competency: k.name, level: ms.level}) AS mastery,
  collect(DISTINCT {interest: n.name, score: i.score}) AS interests,
  collect(DISTINCT o {.date, .source, .level, .note}) AS observations
      
      
      
      
      
        
      Riwayat level satu kompetensi
      
        
      Dasar grafik tren pada detail node.
      

      MATCH (o:Observation)-[:ABOUT]->(:Child {id: $childId})
MATCH (o)-[:MEASURES]->(k:Competency {id: $competencyId})
RETURN o.date AS date, o.level AS level,
       o.enjoyment AS enjoyment, o.source AS source
ORDER BY date
      
      
      
      
      
        
      Beban mingguan dan biaya
      
        
      Menjumlahkan semua kegiatan dan olahraga yang masih berjalan.
      

      MATCH (c:Child {id: $childId})-[r:PARTICIPATES_IN|PRACTICES]->(x)
WHERE r.status = 'active'
RETURN sum(r.hoursPerWeek) AS hoursPerWeek,
       sum(r.monthlyCost) AS monthlyCost,
       collect(x.name) AS activities
